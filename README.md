# Toewaioo's Studio

မြန်မာနှင့် အင်္ဂလိပ်ဘာသာဖြင့် မင်္ဂလာဖိတ်စာဖန်တီး၊ ကြည့်ရှုစစ်ဆေးပြီး လင့်ခ်ဖြင့် မျှဝေနိုင်သော React၊ TypeScript၊ Vite အက်ပ်ဖြစ်သည်။ Love Galaxy သည် သီးခြား 3D အတွေ့အကြုံဖြစ်သည်။

## စတင်အသုံးပြုရန်

လိုအပ်သည်များမှာ Bun နှင့် Git ဖြစ်သည်။

```bash
bun install
cp .env.example .env.local
```

ဒေသတွင်း စမ်းသပ်မုဒ်အတွက် `.env.local` ထဲတွင် `VITE_LOCAL_DEMO=true` ထည့်ပြီး `bun run dev` ဖြင့် စတင်ပါ။ စစ်ဆေးမှုများမှာ `bun run test`, `bun run typecheck` နှင့် `bun run build` ဖြစ်သည်။

## Template များ ထည့်ဝင်ရန်

အသစ်ထည့်မည့်ပုံစံသည် ရှိပြီးသားဖိတ်စာ၏ အသုံးပြုရလွယ်ကူမှု၊ ဖုန်းမျက်နှာပြင်နှင့် လှုပ်ရှားမှုများကို ဆက်လက်ထိန်းသိမ်းပါ။ လက်ရှိဖွဲ့စည်းပုံမှာ—

- `src/templates/registry.ts` — ID၊ အမည်၊ ဖော်ပြချက်၊ နမူနာပုံ၊ မူလအရောင်နှင့် ဖိတ်စာစာသားများ၏ စုစည်းရာ။
- `src/templates/scenes/` — ဒီဇိုင်းတစ်ခုချင်းစီ၏ 3D အလှဆင်မြင်ကွင်း။ `NoirPopup.tsx` နှင့် `RosePopup.tsx` ကို နမူနာယူပြီး `TemplatePopups.tsx` တွင် ချိတ်ဆက်ပါ။ သီးခြားမြင်ကွင်းမလိုပါက မူလမြင်ကွင်းကို အသုံးပြုနိုင်သည်။
- `src/components/invitation.css` နှင့် `src/components/invitation-ornate.css` — ဖိတ်စာအားလုံးမျှဝေသုံးသည့်နှင့် ဒီဇိုင်းအလိုက် CSS။ ရွေးချယ်ကိရိယာ၊ နမူနာပြခန်းနှင့် ဖိတ်စာစာသားများကို registry မှ ဖတ်ယူသည်။
- `public/assets/` — နမူနာပုံနှင့် အခြားပုံဖိုင်များ။ ထည့်သွင်းသည့်ပစ္စည်းတိုင်းအတွက် မူရင်းနှင့် လိုင်စင်ကို မှတ်တမ်းတင်ပါ။

ထည့်ဝင်ရာတွင် ID ကို တည်ငြိမ်စွာထားပါ။ CSS ကို `.invite` အောက်တွင်သာ သတ်မှတ်ပြီး အမည်၊ ဓာတ်ပုံ မရှိသည့်အခြေအနေများနှင့် ဖုန်းမျက်နှာပြင်ပေါ်တွင် စမ်းသပ်ပါ။ ရွေးချယ်ကိရိယာ၊ အများပြည်သူနမူနာ၊ ကြိုတင်ကြည့်ရှုမှု၊ CSS၊ ဖုန်းမျက်နှာပြင်နှင့် ကီးဘုတ်ဖြင့် အသုံးပြုမှုတို့ကို စစ်ဆေးပါ။ `bun run test`, `bun run typecheck`, `bun run build` တို့ကို အောင်မြင်စွာ လုပ်ဆောင်ပြီးမှ တင်ပြပါ။

**ဆာဗာဘက် ကန့်သတ်ချက်:** Browser အပိုင်းတွင် ID ထည့်ရုံဖြင့် template အသစ်ကို မျှဝေအသုံးပြုနိုင်မည်မဟုတ်ပါ။ လက်ရှိ `thazin`, `noir`, `rose` ID များကို API၊ Supabase Edge Function များနှင့် ဒေတာဘေ့စ်က စစ်ဆေးကန့်သတ်ထားသည်။ ID အသစ်လိုအပ်ပါက ဆာဗာခွင့်ပြုစာရင်းနှင့် ဒေတာဘေ့စ်ပြောင်းလဲမှုကို သီးခြားတင်ပြပြီး ခွင့်ပြုချက်ရပြီးမှ ဆောင်ရွက်ပါ။

## ပြောင်းလဲမှု တင်ပြရန်

တင်ပြချက်တွင် ရည်ရွယ်ချက်၊ ပုံဖိုင်များ၏ မူရင်းနှင့် လိုင်စင်၊ ဖုန်းနှင့် ကွန်ပျူတာပေါ် စစ်ဆေးမှု၊ စမ်းသပ်မှုရလဒ်တို့ကို အကျဉ်းရေးပါ။ ခွင့်ပြုချက်မရှိဘဲ API ခွင့်ပြုချက်၊ ဒေတာဘေ့စ်ဖွဲ့စည်းပုံ သို့မဟုတ် အများပြည်သူသုံးစနစ်၏ ပြင်ဆင်ချက်များကို မပြောင်းပါနှင့်။
